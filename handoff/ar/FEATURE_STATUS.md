# حالة الخصائص

**تاريخ المستند:** 2026-11-08 · **إصدار المشروع:** `0.1.0`  
تعبر الحالة عن التنفيذ في المستودع ودليل التحقق المتاح، لا عن توقعات مستقبلية.

| الخاصية المطلوبة | الحالة | الدليل / القيد |
|---|---|---|
| موقع عربي أولًا، RTL وغلاف متجاوب | منفذة ومختبرة | فحوص محلية سابقة أعادت نجاح المسارات؛ المصدر يحدد `lang=ar` وRTL وCSS متجاوبًا. |
| الهوية الرسمية والشعار والخط العربي | منفذة ومختبرة | الأصول محلية؛ لا يوجد خط خارجي. |
| صفحة الفريق والأرشيف التاريخي | منفذة ومختبرة | توجد بيانات وصفحات ثابتة؛ لا توجد واجهة CMS للتعديل. |
| إنتاج واحد بارز وقابل للحجز | منفذة جزئيًا | صفحة «المحلج» التجريبية وإنشاء مسودة موجودان؛ لا توجد بيانات فعلية منشورة. |
| الفصل بين `Production` و`Performance` | منفذة جزئيًا | العلاقة موجودة في المخطط؛ إدارة المواعيد وسير العمل غير مكتملين. |
| مخزون Hall/Balcony والخريطة التفاعلية المطابقة | غير منفذة | توجد صور مرجعية؛ القائمة الآلية canonical ومطابقة الأكواد لم تحسما. |
| مخزون مستقل لكل موعد ومنع البيع المكرر | منفذة جزئيًا | قيد فريد `(performanceId, seatId)` موجود؛ منطق التخصيص والتزامن غير منفذ/مختبر. |
| إعداد أول Super Admin لمرة واحدة | منفذة لكن غير مختبرة | المسار/action ونموذج singleton وMigration موجودة؛ لم تختبر على قاعدة مهاجرة فعلية. |
| دخول الموظفين بالاسم وكلمة المرور والجلسات | منفذة لكن غير مختبرة | الكود موجود؛ تم فحص hash/verify محليًا فقط وليس تدفق الدخول كاملًا. |
| إدارة حسابات الموظفين بواسطة Super Admin | منفذة لكن غير مختبرة | واجهة/actions لـAdmin وBooking Officer وScanner موجودة؛ صلاحيات قاعدة البيانات لم تتحقق. |
| لوحات الأدوار والصلاحيات على الخادم | منفذة جزئيًا | المسارات والفحوص موجودة؛ مصفوفة الصلاحيات واختبارات المنع لم تكتمل. |
| حجز العميل كضيف دون حساب | منفذة جزئيًا | صفحة الحجز توضح عدم الإتاحة؛ تدفق الحجز الفعلي دون حساب غير منفذ. |
| إنتاج «المحلج» التجريبي | منفذة جزئيًا | صفحة مؤقتة وإنشاء مسودة؛ لم تُختلق مواعيد أو أسعار أو مقاعد. |
| حجز ضيف إلكتروني (1–9 تذاكر) والتوصيل ورابط المتابعة وإثبات الهوية المشروط | غير منفذة | لا نموذج حجز ولا رابط متابعة خاص أو توصيل أو رفع آمن. لا يلزم OTP. المراجعة القانونية مفتوحة. |
| حجز مجموعة ومدة 25 دقيقة وتحصيل الموظف | غير منفذة | حقول/سياسات بالمخطط والتوثيق؛ لا workflow أو مؤقت أو تحصيل. |
| مهلة 15 دقيقة لإثبات InstaPay الإلكتروني وحجز انتظار المراجعة | غير منفذة | السياسة موثقة: الإثبات المرفوع في الوقت يبقى محجوزًا حتى مراجعة Admin/Super Admin دون انتهاء تلقائي؛ لا معاملة hold أو queue أو worker. تحل محل صياغات أقدم متعارضة. |
| الخصومات المعتمدة ومجانيات الفريق/الضيوف وموافقة Admin | غير منفذة | السياسات/بعض الحقول موجودة؛ لا موافقة أو تحقق استحقاق أو تقارير. |
| دفع المجموعة كاملًا Cash/InstaPay ومراجعة إثبات InstaPay الإلكتروني | غير منفذة | توجد enums/حقول فقط؛ لا مسار إثبات أو تحقق تحصيل. لا تكامل مزود أو بوابة آلية. |
| سياسة الإلغاء والاسترداد والتأجيل | غير منفذة | السياسات موثقة؛ لا workflow تشغيلي أو قدرة مزود مؤكدة. |
| PDF للتذكرة وإصدار QR فريد | غير منفذة | النموذج موجود؛ لا توليد token أو PDF أو إرسال أو إصدار. |
| ماسح QR ومنع التكرار | غير منفذة | صفحة/دور Scanner موجودان؛ لا كاميرا أو استرداد خادمي ذري أو واجهة مكتملة. |
| عمليات وتقارير Admin وإتاحة التقارير للموظف | منفذة جزئيًا | صفحة Admin وواجهة الحسابات موجودتان؛ أدوات الحجز/المالية/المقاعد/التقارير وإتاحة تقارير الموظف غير موجودة. |
| تصدير CSV/Excel لـAdmin/Super Admin وفلاتره | غير منفذة | لا تنفيذ للتصدير؛ لا يحق للموظف التصدير. |
| سجل العمليات | منفذ جزئيًا | نموذج وكتابة بعض أحداث الحساب موجودان؛ الاكتمال والاستمرارية وتدقيق الملفات الحساسة غير متحقق منها. |
| تخزين هوية خاص وتدقيق الوصول والاحتفاظ والحذف | غير منفذة | يوجد نموذج metadata فقط؛ لا تخزين أو صلاحيات ملفات. الموافقة القانونية لازمة. |
| مخطط قاعدة البيانات وmigrations | منفذة ومختبرة | نجح سابقًا التحقق من Prisma وتوليد العميل؛ توجد ثلاث migrations. حالة التطبيق/runtime غير متحققة. |
| تشغيل PostgreSQL المحلي للمشروع | منفذة لكن غير مختبرة | Compose/script يستخدمان 5433؛ فُحص تركيب السكربت في PowerShell 5.1 و7.6.9، ولم يُختبر بدء التشغيل كاملًا. |
| استضافة إنتاج وقاعدة/ملفات سحابية ومراقبة ونسخ | غير منفذة | لم تتصل خدمة ولم يحدث نشر. |
| حزمة اختبارات آلية | غير منفذة | لم يوجد script أو suite للاختبارات في `package.json`. |

## حدود أدلة الاختبار

الفحوص السابقة المسجلة: TypeScript no-emit وESLint وPrisma validation/generation وNext production build منفصل وفحوص HTTP لمسارات عامة محددة نجحت. والمالك يفيد بأن الموقع يعمل محليًا. لا يثبت أي منها عمل مصادقة الموظفين على قاعدة مهاجرة أو الحجز الكامل أو الدفع. لم يختبر تدفق بدء Windows كاملًا؛ لا تدّعِ ذلك.
